# 003. Data Collection For LLM Training

## Main idea

Before an LLM can be trained, companies need to build a very large training corpus.

A training corpus is a huge collection of text, code, and sometimes multimodal data that is later cleaned, filtered, tokenized, and used for model training.

Common Crawl is one of the most important public sources of raw web data, but it is not the only source.

---

## What Common Crawl is

Common Crawl is a nonprofit organization that crawls the public web and publishes large web archives for free public use.

Important facts:

| Fact | Value |
| --- | --- |
| Organization type | Nonprofit 501(c)(3) |
| Founded | 2007 |
| Data collected since | 2008 |
| Founder | Gil Elbaz |
| Archive size | More than 10 PiB |
| Pages per crawl | Usually 2B+ pages |
| Crawl frequency | Approximately monthly |
| Hosting | Amazon Web Services, AWS Open Data Sponsorship Program |
| Crawler | CCBot, based on Apache Nutch |

Common Crawl stores raw web data, metadata, extracted text, and indexes.

| Format | Meaning |
| --- | --- |
| WARC | Raw web archive data, including HTTP responses. |
| WAT | Metadata extracted from WARC records. |
| WET | Plain text extracted from HTML. |
| Indexes | Files used to find pages in the archive. |

Common Crawl is not a clean AI dataset by itself. It is closer to a raw archive of the public internet.

---

## How raw web data becomes training data

The simplified pipeline is:

```text
public web
-> crawler
-> raw archive
-> text extraction
-> language detection
-> quality filtering
-> deduplication
-> safety filtering
-> source mixing
-> tokenization
-> model training
```

Typical filtering steps:

| Step | Purpose |
| --- | --- |
| HTML cleanup | Remove menus, ads, scripts, boilerplate, broken markup. |
| Language detection | Identify the language of each document or text block. |
| Deduplication | Remove duplicate pages, mirrors, reposts, copied articles. |
| Spam filtering | Remove SEO spam, keyword stuffing, link farms, junk pages. |
| Quality filtering | Keep better-written, more useful, more informative text. |
| Safety filtering | Reduce toxic, illegal, or unsafe material. |
| PII/secrets filtering | Remove emails, passwords, API keys, private data where possible. |
| Domain/source weighting | Give more or less weight to different sources. |

The difficult part is not only collecting data. The difficult part is deciding what to keep, what to remove, and how much weight each source should have.

---

## Is Common Crawl the only internet source?

No.

Common Crawl is a major public raw source, but leading companies usually combine many sources.

| Source type | Example |
| --- | --- |
| Public web archive | Common Crawl. |
| Company crawlers | Private crawlers operated by AI or search companies. |
| Search engine indexes | Google Search index, Bing index, and similar private indexes. |
| Licensed data | Paid agreements with publishers, news sites, book owners, platforms. |
| Open datasets | FineWeb, The Pile, Dolma, C4, RefinedWeb, The Stack. |
| Code repositories | GitHub, GitLab, package registries, public code archives. |
| Academic sources | arXiv, PubMed-like sources, papers, textbooks where allowed. |
| Human data | Human-written prompts, demonstrations, ratings, feedback. |
| Synthetic data | Data generated by other models and then filtered. |

So the correct picture is:

```text
Common Crawl
+ company crawls
+ search indexes
+ books
+ code
+ Wikipedia
+ academic text
+ licensed data
+ human feedback data
+ synthetic data
+ filtering and mixing
= final training corpus
```

---

## Do all leading companies use exactly the same Common Crawl database?

No.

Many models have used filtered Common Crawl data, but each company usually builds its own final dataset.

Public examples:

| Model / dataset | Publicly known point |
| --- | --- |
| GPT-3 | A large part of the published training mix came from filtered Common Crawl, together with WebText2, Books1, Books2, and Wikipedia. |
| Google T5 / C4 | C4 was created by filtering a Common Crawl snapshot. |
| FineWeb | 15T-token dataset derived from 96 Common Crawl snapshots. |
| The Pile | Open English dataset that included Pile-CC, a Common Crawl component, plus many other sources. |
| The Stack | Public code dataset built from permissively licensed source code. |

For modern frontier models, exact dataset composition is usually private.

Companies may say broad categories such as:

```text
publicly available data
licensed data
human-generated data
code
books
web documents
multimodal data
```

But they usually do not publish the exact URLs, source weights, filtering rules, or final training mixture.

---

## Does Google have more information than Common Crawl?

Very likely yes, but this does not mean all of it is used for training.

Google has its own search index, crawlers, books infrastructure, YouTube, Android, Chrome, Maps, Workspace, and many other data channels.

However:

```text
having access to data
is not the same as
having permission or policy approval to train on that data
```

So the careful answer is:

- Google almost certainly has broader raw web infrastructure than Common Crawl.
- The exact Gemini training data mixture is not public.
- Public descriptions of Gemini mention a multimodal and multilingual dataset with web documents, books, code, image, audio, and video data.
- Private user/product data use depends on company policy, user settings, contracts, and law.

---

## Rights and permissions

Rights and permissions are one of the most controversial parts of LLM training.

Common approaches:

| Approach | Meaning |
| --- | --- |
| Public web crawl | Use pages publicly reachable on the web. |
| robots.txt compliance | Avoid pages blocked by site owners for that crawler. |
| Licensed data | Pay or sign agreements with data owners. |
| Open-license data | Use public-domain or permissively licensed content. |
| Opt-out systems | Allow creators or site owners to request exclusion. |
| Fair-use argument | Claim training on public data is legally allowed, especially in some jurisdictions. |

Common Crawl says its crawler can be blocked through `robots.txt` using:

```text
User-agent: CCBot
Disallow: /
```

But even if data is publicly crawlable, copyright, database rights, contract rules, privacy law, and platform terms may still matter.

There is no single global legal answer yet.

---

## Who does the work?

There are usually several groups involved.

| Group | Work |
| --- | --- |
| Crawling/infrastructure engineers | Run crawlers, storage, indexes, distributed processing. |
| Data engineers | Extract, clean, deduplicate, filter, format data. |
| ML researchers | Test data mixtures and measure model quality. |
| Safety teams | Remove or reduce unsafe data and evaluate risks. |
| Legal/licensing teams | Review data rights, contracts, opt-outs, policy constraints. |
| Human data teams | Create/rate instruction-following and preference data. |

For open datasets, this work may be done by universities, nonprofits, open-source communities, or research labs.

For frontier labs, the final pipeline is usually private and continuously maintained.

---

## How long does it take?

Very roughly:

| Scale | Time |
| --- | --- |
| Small research dataset | Days or weeks. |
| Serious open pretraining corpus | Weeks or months. |
| Frontier-company corpus | Months and then continuous maintenance. |

Large companies do not usually build the corpus once and stop. They keep improving the pipeline: new crawls, new filters, new licensed sources, new safety rules, new synthetic data, and new evaluation results.

---

## Short conclusion

Common Crawl is one of the main public raw sources for LLM training data.

But it is not the only source and not a clean training corpus by itself.

The valuable part is the full pipeline:

```text
raw data collection
+ rights/licensing decisions
+ cleaning
+ deduplication
+ quality filtering
+ safety filtering
+ source mixing
+ tokenization
= training corpus
```

The exact training corpus used by leading AI companies is usually private.
