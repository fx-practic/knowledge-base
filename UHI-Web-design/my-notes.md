# Web Design Notes

## Bounce rate

**Bounce rate** — the percentage of website visits where the user leaves without meaningful interaction with the site.

A **high bounce rate** may indicate that the page is irrelevant, slow, difficult to use, or that the visitor found the information they needed without visiting another page.

## Basic design elements

| Element | Meaning / example |
|---|---|
| **Line** | A visible or implied path that separates, connects, or guides the eye. Example: borders, dividers, underlines. |
| **Color** | Creates contrast, mood, emphasis, and visual hierarchy. Example: using a bright color for a call-to-action button. |
| **Shape** | A two-dimensional area defined by boundaries. Example: circles, rectangles, icons, buttons. |
| **Texture** | The visual appearance of a surface; can make a design feel smooth, rough, natural, etc. Example: a paper-like background. |
| **Framing** | Uses boundaries or surrounding elements to focus attention on content. Example: a card, box, border, or image crop. |
| **Type** | The visual use of text: font, size, weight, spacing, and alignment. Example: large bold headings and smaller body text. |

### Other commonly included elements

| Element | Meaning / example |
|---|---|
| **Form** | The appearance of three-dimensional volume or depth. Example: shadows or perspective making a button look raised. |
| **Space** | The area around and between elements, including whitespace. It improves readability and separation. |
| **Value** | How light or dark a color or element is. Example: using dark text on a light background for contrast. |
